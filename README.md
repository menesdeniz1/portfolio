# Enes Deniz — personal portfolio source

Current personal-site snapshot built with Next.js, React, TypeScript and Tailwind. This September 2026 publication edition starts a new history; the original repository and inherited blog/template history are preserved in a private local backup, not redistributed here.

The earlier site was based on [leerob/next-mdx-blog](https://github.com/leerob/next-mdx-blog). Old upstream blog content, key-like examples and environment files are excluded. This snapshot must not be presented as proof that all historical framework/template work was authored by Enes Deniz. No blanket third-party license is granted.

## Run

Use Node.js 22: `npm ci`, `npm run dev`. Build with `npm run build`. Google font downloads require internet access. Source publication does not deploy the site or verify ownership of referenced external domains.
